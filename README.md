# Gita Picture Book · Chapter 1

The Bhagavad Gītā, Chapter 1, one illustrated, animated and recited śloka at a time. It installs as a phone app (PWA).

Open the app: **https://raghavan-gita.github.io/gita-picture-book/**

On iPhone: open the link in Safari, then Share → Add to Home Screen.
On Android: open the link in Chrome, then Install app.
